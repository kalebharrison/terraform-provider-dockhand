# Governance

## Model

This project currently follows a maintainer-led model.

- Final technical decisions are made by maintainers.
- Changes are proposed via issues and pull requests.
- CI, tests, and release policy are enforced by repository rules.

## Decision Process

1. Open or link an issue.
2. Submit a PR with `Fixes #...` or `Refs #...`.
3. Ensure required checks pass.
4. Merge via protected branch workflow.

## Evolution

As the maintainer team grows, this document can be updated to define additional roles and voting/escalation processes.
