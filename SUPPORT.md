# Support

## Usage Questions

Use GitHub Discussions or open a question issue if Discussions are not enabled.

## Bug Reports

Open a bug issue using the bug report template and include:

- provider version
- Terraform/OpenTofu version
- Dockhand version
- minimal reproducible configuration
- full error output

## Feature Requests

Open a feature request issue with:

- use case
- desired HCL UX
- relevant Dockhand API endpoint(s), if known
