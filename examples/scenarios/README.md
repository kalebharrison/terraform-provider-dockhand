# Scenario Examples

These examples are intended to be copied as starting points for real Dockhand workflows.

- `bootstrap-admin` — create the first Dockhand admin on a fresh installation using `allow_unauthenticated`
- `environment-and-stack` — register a Docker environment, tune a basic UI setting, and deploy a stack
- `gitops-stack` — configure Git credentials, repository integration, a Git stack, and a managed env file
- `registry-and-image` — configure a registry and perform image management actions

The per-resource examples under `examples/resources` and `examples/data-sources` remain the canonical reference for individual schema usage.
